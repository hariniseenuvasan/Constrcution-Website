Construction Company Website

Overview

A responsive construction company website developed as a UI development task.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Navigation menu
- About section
- Construction services
- Projects section
- Testimonials section
- Contact form
- Responsive layout

Installation

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser.

Development

HTML is used for the page structure, CSS for styling and responsive layouts, and JavaScript for basic interactions.

Build

No build command is required. This is a static website.

Deployment

Hosted using Netlify.

Limitations

- The contact form is a front-end demonstration and does not send form data to a server.
- Some images are loaded from external URLs.

Assumptions

The website is a static UI implementation using HTML, CSS, and JavaScript.
